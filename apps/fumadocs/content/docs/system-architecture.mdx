Selvam is a 100% sovereign, local-first financial application. The interface runs natively inside a Tauri 2.0 shell (macOS, Windows, Linux, Android) or as a local Progressive Web App (PWA). All authentication, document parsing, financial calculations and database storage execute entirely on-device without any mandatory third-party or cloud dependencies.

## Primary request and data path

The emphasized path represents the sovereign financial import and computation flow:

<Steps>
  <Step title="Select local financial statements">
    The user selects broker exports (Zerodha, Degiro), bank statements, or salary payslips (XLSX,
    CSV, PDF) directly on their local device.
  </Step>
  <Step title="Verify the sovereign session">
    Next.js route handlers verify the local Better Auth session. In sovereign mode
    (`SOVEREIGN_MODE=true`), authentication automatically binds to the local sovereign identity
    (`sovereign-user`).
  </Step>
  <Step title="Universal parsing via @portfolio/parsers">
    The zero-dependency universal parser engine parses the raw file bytes into normalized ledger
    entries, audit fingerprints, and dated snapshots without side effects.
  </Step>
  <Step title="Encrypted document vault archiving">
    Original statements are archived into the local disk vault (`./data/vault/documents/`) with
    SHA-256 integrity fingerprints and optional AES-256-GCM encryption.
  </Step>
  <Step title="Embedded PGlite persistence">
    Drizzle ORM persists owner-scoped rows, snapshots, and ledger events directly into the embedded
    WASM PostgreSQL database (`./data/selvam.db`) in ~450ms without Docker daemons.
  </Step>
  <Step title="Pure calculations via @portfolio/calc">
    Pure mathematical calculations for FIRE projections, XIRR returns, net worth summaries, and
    currency conversions execute deterministically with zero database or network dependencies.
  </Step>
</Steps>

Reads follow the reverse local path: server-only API services query account-scoped records from the embedded PGlite instance, fetch zero-key ECB daily reference rates when needed, and pipe derived series to interactive ECharts and the ephemeral 6-second Financial Stories pulse.

## Trust and ownership boundaries

| Boundary                              | Responsibility                                                                                                                                                                              |
| ------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Device Shells & Local Files**       | Tauri 2.0 native shell (macOS, Windows, Linux, Android) or local browser. Financial statements and identity keys remain user-controlled on the local filesystem.                            |
| **Sovereign Application Boundary**    | Next.js 16 host running locally on loopback (`127.0.0.1:3001`). Protected routes, Server Actions, and API handlers never leak data externally.                                              |
| **Authenticated Vault & Domain Core** | AES-256-GCM Hardware Vault with PBKDF2-SHA512 key derivation. Domain interactors in `@portfolio/api`, universal parsers in `@portfolio/parsers`, and calculation math in `@portfolio/calc`. |
| **Sovereign Embedded Storage**        | Embedded WASM PGlite database engine persisting 70 relational tables to `./data/selvam.db`, alongside the encrypted local document vault under `./data/vault/documents/`.                   |

The entire application runs completely air-gapped without external network access. For multi-currency portfolios, official European Central Bank (ECB) daily reference rates are fetched directly from ECB XML endpoints without intermediary API aggregators or API keys.

## Historical integrity

Imports are additive, idempotent, and auditable rather than destructive. SHA-256 file and row hashes prevent duplicate uploads from altering portfolio history. Original source documents are securely stored in the local disk vault (`./data/vault/documents/`) with cryptographic fingerprints, ensuring complete auditability without reliance on external cloud storage.
