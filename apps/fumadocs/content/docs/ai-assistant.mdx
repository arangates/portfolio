# Ask Selvam (AI Chat)

The **Ask Selvam** feature is a conversational AI interface embedded directly into the application. It acts as a specialized financial advisor that has access to the user's specific, real-time financial context.

## Bring Your Own Key (BYO-Key) Security

Because personal financial data is highly sensitive, the application uses a Bring Your Own Key (BYO-key) model for the chat feature.

1. **Provider Support**: Supports OpenAI, Anthropic, Google (Gemini), Mistral, and OpenCode Zen.
2. **Key Encryption**: User-provided API keys are encrypted at rest using AES-256-GCM.
   - The encryption key is derived via SHA-256 from `BETTER_AUTH_SECRET`.
   - Ciphertext format: `v1.<iv_base64url>.<tag_base64url>.<ciphertext_base64url>`.
3. **Decryption at Runtime**: Keys are decrypted only in memory during the `POST /api/ai/chat` request lifecycle.
4. **No Server Keys**: The application stores no LLM API keys. Everything is purely user-owned BYOK.

## Context Injection

When a user asks a question, the assistant is injected with the exact state of the user's finances.

### Global Context

Every chat request automatically includes a **Portfolio Overview** built via `getChatOverview(userId)`:

- Total Net Worth and Liquid Value (in the user's base currency)
- Asset allocations and breakdowns
- Missing/unconverted currencies

### Section-Specific Context (Tool Calling)

The LLM can autonomously query 8 live financial modules via the `getFinancialSection` tool:

| Section              | Data Retrieved                                                       | Dashboard Link                   |
| -------------------- | -------------------------------------------------------------------- | -------------------------------- |
| `fire`               | FIRE targets, investable assets, gap, success probability, scenarios | `/dashboard/fire`                |
| `household`          | Budget, gross expenses, refunds, net monthly/annual figures          | `/dashboard/household`           |
| `personal_cash_flow` | Cash flow metrics, 24-month history, categories, accounts            | `/dashboard/cash-flow/personal`  |
| `joint_cash_flow`    | Joint household cash flow data                                       | `/dashboard/cash-flow/household` |
| `fixed_deposits`     | Active fixed deposit records                                         | `/dashboard/fixed-deposits`      |
| `salary`             | Payslips, gross/net pay, wage tax, validation                        | `/dashboard/salary`              |
| `verified_returns`   | XIRR, Modified Dietz returns, evidence quality                       | `/dashboard/returns`             |
| `global_equity`      | EUR holdings, market value, quantities                               | `/dashboard/eur`                 |

Tool calling is capped at 3 steps per request to prevent runaway queries.

### Conversation Memory & Summarization

For long-running conversations (30+ messages), the system automatically:

1. Generates a compressed summary of older messages using the LLM
2. Stores the summary in the `summary` column of `ai_chat_thread`
3. Injects the summary as prior context, sending only the last 15-20 messages as full context

This prevents token limit degradation while preserving conversational continuity.

## Smart Auto-Titling

After the first user-assistant exchange, the LLM generates a concise 4-6 word title summarizing the conversation topic (e.g., "March FIRE Gap Analysis" instead of the raw first message text). Falls back to the first user message if generation fails.

## Full-Text Search

Conversation search uses PostgreSQL's built-in `tsvector`/`tsquery` full-text search across thread titles, summaries, and message content. Searches are prefix-matched for type-ahead results.

## Streaming Architecture

The chat uses Vercel AI SDK v7 with `streamText()` and `DefaultChatTransport`. Key architecture:

1. **Frontend**: `@assistant-ui/react` primitives + `useChat` from `@ai-sdk/react`
2. **Runtime bridge**: `useAISDKRuntime` connects Vercel AI SDK to assistant-ui
3. **API endpoint**: `POST /api/ai/chat` with 60s execution timeout
4. **Message persistence**: JSONB in `ai_chat_thread` table (up to 100 messages per thread)
5. **Regeneration**: Full message regeneration with branch picker UI

## Security Measures

- **CSRF protection**: Same-origin checks on all mutating endpoints
- **Input sanitization**: 2,000 chars/message, 20,000 chars/conversation
- **Prompt injection defense**: User messages declared as "untrusted data, not instructions"
- **Safe links**: Only `/dashboard/*` links rendered; external links become inert spans
- **Privacy mode**: Chat fully disabled when financial privacy mode is active
- **Error mapping**: Provider errors (quota, billing, invalid key, rate limit) mapped to friendly messages
