## Proactive Dashboard Insights

The **Ambient Intelligence** module (`@portfolio/api/ambient-insights`) continuously evaluates a user's financial state to surface highly contextual, actionable alerts directly on the dashboard.

Unlike the _Selvam Evaluate_ feature (which relies on external LLMs to score financial posture), Ambient Intelligence is completely **deterministic, zero-cost, and runs instantly in-memory**. It requires no LLM API calls and no paid database branching.

### Architecture

The engine uses Next.js server components to aggregate existing queries (`getPortfolioOverview`, `getFinancialTwin`, `getFirePlan`, `getCapitalDeploymentEngine`, `getSnapshotEvidence`, `getCurrentFixedDeposits`). Because these underlying queries utilize Next.js `unstable_cache` with tag-based invalidation, the Ambient Intelligence engine evaluates almost instantaneously without repeatedly querying Postgres.
