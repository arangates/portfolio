## Hypothetical Modeling

The **Scenario Engine** (`@portfolio/api/scenario-engine`) allows users to simulate the financial impact of future life events (e.g., buying a house, taking a sabbatical, suffering a market crash) against their live FIRE projections.

### Zero-Cost Architecture

Simulating financial scenarios typically requires either complex database branching (cloning the database to mutate records) or expensive LLM reasoning.

The Selvam Scenario Engine avoids both. It is a **pure-math, in-memory projection engine**. It reads the baseline data from `getFirePlan` and `getFinancialTwin`, applies hypothetical adjustments mathematically during the API request, and calculates the delta in years to FIRE without ever touching the database or triggering a third-party API.

<InfoPanel title="Scenarios do not change your records" icon="ShieldCheck" tone="tip">
  Adjustments exist only for the current projection request. They do not write to the portfolio,
  change saved assumptions or contact an external model provider.
</InfoPanel>

### Preset Scenarios

The engine ships with several built-in presets accessible via the `GET /api/scenarios` endpoint:

- **20% Market Crash**
- **6-Month Sabbatical**
- **50% Salary Raise**
- **Buy a ₹1Cr House**

### Output format

The endpoint returns both the baseline metrics and the projected metrics, allowing the UI to render a clean diff. It also generates a human-readable `impact` string (e.g., _"Your FIRE date is delayed by 2.4 years"_).
