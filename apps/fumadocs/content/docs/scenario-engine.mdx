## Hypothetical Modeling

The **Scenario Engine** (`@portfolio/api/scenario-engine`) allows users to simulate the financial impact of future life events (e.g., buying a house, taking a sabbatical, suffering a market crash) against their live FIRE projections.

### Zero-Cost Architecture

Simulating financial scenarios typically requires either complex database branching (cloning the database to mutate records) or expensive LLM reasoning. 

The Selvam Scenario Engine avoids both. It is a **pure-math, in-memory projection engine**. It reads the baseline data from `getFirePlan` and `getFinancialTwin`, applies hypothetical adjustments mathematically during the API request, and calculates the delta in years to FIRE without ever touching the database or triggering a third-party API.

### Supported Adjustments

The engine supports multiple adjustment primitives that can be stacked together in a single scenario:

- `lump_expense`: A one-time outflow that instantly reduces the current investable corpus (e.g., a downpayment).
- `extra_savings`: A flat monthly increase to the available surplus.
- `income_change`: A percentage-based adjustment to the monthly surplus (e.g., a 50% raise).
- `market_crash`: A percentage-based drop in the total investable corpus.
- `sabbatical`: Zeros out all monthly surplus for a defined duration (in months) and actively drains the corpus to cover baseline living expenses during that time.

### Preset Scenarios

The engine ships with several built-in presets accessible via the `GET /api/scenarios` endpoint:
- **20% Market Crash**
- **6-Month Sabbatical**
- **50% Salary Raise**
- **Buy a ₹1Cr House**

### Output format

The endpoint returns both the baseline metrics and the projected metrics, allowing the UI to render a clean diff. It also generates a human-readable `impact` string (e.g., *"Your FIRE date is delayed by 2.4 years"*).
